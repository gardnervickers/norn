Performance comparison:
Same Ryzen 9 5950X/Linux 6.18.55 host, performance governor, boost enabled.
Single-thread benchmarks: CPU 15. Channel: consumer 2, producers 4,6,8,10.
Reran the original 106-case matrix. Three interleaved pairs for each of six
key cases add 36 measurements (142 total), using frozen old/new binaries.
Percentages below are medians of per-pair candidate/baseline - 1;
negative ns/iteration means faster. Ranges show the three paired deltas.

Task yield, 128 tasks x 32 yields:
  35,973 -> 36,542 ns/iteration;
  paired median +1.53% (+1.36% to +3.93%).
Executor spawn, 1024 tasks:
  39,944 -> 39,717 ns/iteration;
  paired median -0.57% (-1.40% to +0.39%).
io_uring noop, 64 tasks / about 100k operations:
  14,595,443 -> 13,705,752 ns/iteration;
  paired median -6.10% (-6.48% to -4.62%).
Sharded channel, 4 producers / 262144 messages:
  1,019,651 -> 1,014,211 ns/iteration;
  paired median -0.63% (-1.74% to -0.29%).
TCP normal, 8 connections x 512 requests / 1024 bytes:
  47,856,675 -> 47,926,007 ns/iteration;
  paired median +0.14% (-0.43% to +0.63%).
UDP single, window 64 / 4096 requests / 64 bytes:
  32,363,093 -> 32,246,767 ns/iteration;
  paired median -0.36% (-0.39% to -0.32%).

End-to-end KV: original frozen independent client and mixed-1w profile;
server CPU 15, client CPUs 8-11; three interleaved server pairs.
All six runs passed correctness and all six capacity segments qualified.
  capacity throughput: 757,836.18 -> 758,935.58; paired median -1.38%; verdict noise.
  capacity user_instructions/op: 1,127.85 -> 1,094.23; paired median -2.98%; verdict better.
  capacity instructions/op: 3,729.52 -> 3,697.58; paired median -0.85%; verdict better.
  capacity cpu_ns/op: 997.48 -> 995.91; paired median +1.62%; verdict noise.
The strongest end-to-end result is 2.98% fewer server user instructions per
request, improving in all pairs (-3.18% to -2.78%). Throughput and CPU-time
movements are noise. Some open-loop segments of two runs were unqualified
because of CPU/SMT contention; do not infer a latency improvement or regression.

Filesystem follow-up: the cross-day matrix appeared slower on put/delete.
Three additional interleaved pairs for 64-byte values / 8 operations measured
61,479,660 -> 60,893,322 ns/iteration, paired median -0.96%, range -5.26% to
+0.42%. The large matrix slowdown did not reproduce; no storage gain claimed.

Conclusion: retain the upgrade. The no-op case improves materially, and KV
server user-instruction cost improves consistently. Task yield is 1.53% slower
in the paired median; retain that tradeoff in subsequent performance work.
